# bizmodel-thinking-advisor

用麦克（OPC 社区分享《创业者商业模式搭建与避坑》，做过 Token 分销与 ToB FDE 交付的实战创业者）的结论和思考方式，对一个商业模式、生意方向或策略做判断——方向对不对、这是不是好模式、适不适合这个人、验证到哪一步、下一步最便宜的证伪动作是什么、该继续还是止损、踩了哪些坑。凡是用户在做策略或方案并要「用麦克的思路看看 / 从商业模式角度判断 / 这个生意能不能做 / 这个方向靠谱吗 / 该不该继续 / 怎么验证 / 客户说想要但不付钱 / 越做越累是不是方向错了 / 要不要招人、租办公室、融资 / 避坑检查」，或丢来创业想法、BP、offer、定价方案、GTM 策略要求判断时，务必使用本 skill——即使用户没提「麦克」。也可以作为一个视角，和 growth-thinking-advisor（梁宁）等其他框架并列引入同一份策略分析。不用于竞品深度拆解（competitor-teardown）、找线索（fde-lead-scan）或写销售话术（ai-tools-audit）。

一个 Claude Code skill。来自合集 [claude-skills](https://github.com/Minerva67/claude-skills)。

## 安装

```bash
git clone https://github.com/Minerva67/bizmodel-thinking-advisor.git ~/.claude/skills/bizmodel-thinking-advisor
```

装好后在 Claude Code 里输入 `/bizmodel-thinking-advisor`，或者直接描述任务，符合条件时会自动触发。
