# bizmodel-thinking-advisor：判断一门生意值不值得继续做

你有一个生意方向、一份定价方案，或者一个卡住的项目，想知道该继续、调整还是止损。这个 skill 用一位实战创业者的结论和思考方式来判断你这件具体的事。他叫麦克，做过 Token 分销和 ToB 企业交付，亏过，也跑通过。

它不复述课程内容，而是落到你的情况上：现在卡在哪一关，下一步做什么成本最低，出现什么结果就说明这条路不通。

## 适合什么时候用

- 这个方向能不能做，这是不是一个好模式
- 客户说想要，但一直不付钱
- 越做越累，不确定是方向问题还是执行问题
- 要不要招人、租办公室、融资
- 一个热点要不要追
- 做了几个月没有起色，要不要继续

## 你会拿到什么

一份固定格式的判断，大约一屏长：

- **决策**：把你的困惑重述成一个明确的决定
- **定位**：谁付钱、为什么付给你、付多少、能不能持续付，哪一项讲不清；现在卡在需求、付费还是规模哪一关
- **判断**：一句话结论，以及它依赖的假设
- **依据**：2–3 条，说明每条在你这件事上意味着什么
- **下一步**：1–3 个动作，每个带时限和证伪条件
- **失败方式与止损**：最可能失败的方式、早期信号和止损线

## 它怎么判断

- 只认已经发生、并且付给你的钱。意向、点赞、「很感兴趣」都不算。
- 先假设会失败，找成本最低、最快能暴露问题的动作，默认以 3 个月为一个周期。
- 先看同行亏在哪，再看他们做对了什么。
- 跑通之前不做重投入：招人、办公室、融资往后放，官网和 PPT 要尽早做好。

他的经验主要来自国内 ToB 企业服务和小团队。用在 ToC、平台、重研发或靠融资扩张的项目上时，它会说明哪些结论要打折扣。

## 怎么用

- 「用麦克的思路帮我看看这个方向」
- 「客户说想要但不付钱，怎么办」
- 「做了三个月没起色，要不要停」

可以和 [growth-thinking-advisor](https://github.com/Minerva67/growth-thinking-advisor)（梁宁《增长思维 30 讲》框架）一起用：那份看机会、模式和战略，这份看生意在实际运营中跑不跑得通。两边结论冲突时，它会指出冲突点，并按你所处的阶段建议参考哪一边。
